Product · apps

Every AI app,its own key

Each AI app you connect gets its own key and sees only the folders you tick. Setup takes a minute: make a key in your vault, paste one block into the app, restart it.

Connect an app

  1. Make a key

    In your vault, open Apps. Name the app, tick the folders it may read, and choose whether it may suggest memories to your inbox. Press Create app key.

  2. Copy the config

    The vault shows the key once, inside a ready config block with your server address. Copy it now: it is not stored anywhere you can see it again.

  3. Paste it into the app

    Add the block to the app's MCP settings (below), save, and fully restart the app. It starts the connector with npx; Node.js 22.13 or newer is the only thing it needs.

MCP configuration
{
        "mcpServers": {
          "synovax": {
            "command": "npx",
            "args": ["-y", "synovax", "connector"],
            "env": {
              "VAULT_APP_KEY": "vlt_app.<app id>.<secret>",
              "VAULT_URL": "https://synovax.tech"
            }
          }
        }
      }

Where it goes, app by app

AppWhere to paste
Claude DesktopSettings, Developer, Edit Config (claude_desktop_config.json). Quit and reopen Claude.
Claude Codeclaude mcp add synovax --scope user --env VAULT_APP_KEY=… --env VAULT_URL=… -- npx -y synovax connector

VS Code.vscode/mcp.json, with "servers" instead of "mcpServers" and "type": "stdio".
Any MCP appAny app that starts an MCP server over standard input and output takes the same command and environment.
On Windows

Some apps cannot start npx directly. Use "command": "cmd" with "args": ["/c", "npx", "-y", "synovax", "connector"]. The vault writes it this way for you when you make the key on Windows.

What the app can do

list_folders

The names of the folders it may read, so it knows what kinds of context exist.

search_memories

Search those folders, on your computer, by words (and by meaning if you turned it on).

read_memory

One memory in full, by its id.

suggest_memory

Only if you allowed it: a suggestion that waits in your inbox.

Every call is written to your read log and sealed with its hour. Text the app receives is quoted as data, with hidden instructions removed first.

Change or revoke

  • Edit an app to tick or untick folders, or allow or stop suggestions. A folder you take away gets a new key, so a copy the app kept stops working.
  • Revoke an app and its key stops working on its very next request. The folders it could read get new keys.
  • Each app card shows its folders and when it was last used. Up to 50 apps per vault.
Keep keys out of git

An app key can read the folders you granted. Prefer the user-level config file over a project file that might be committed, and give each app only the folders it needs.
